# Домашнее задание 1

Проект демонстрирует восемь встроенных типов Python, формирует отчёт
с ФИО и вычисляет MD5 и SHA-256 от одних и тех же UTF-8 байтов.
По запросу программа отправляет письмо с ФИО и хешами.

## Запуск в Ubuntu

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install -e .
python -m pytest -q
python -m homework.main
```

## Отправка письма

Перед запуском задаются переменные окружения SMTP_HOST, SMTP_PORT,
SMTP_USER и EMAIL_TO. Команда отправки:

```bash
python -m homework.main --send
```

Пароль приложения запрашивается скрытым вводом. Он не хранится
в исходном коде и Git.
